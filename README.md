# The Book Did This

A giant glowing golden Garuda bursts out of a little boy's picture book in a
dark bedroom at night — pages and golden feathers exploding outward, embers
spiraling through the air, while the tiny kid in striped pajamas sits on the
rug below looking straight up in awe, one small arm raised toward the huge
bird. The entry program simply copies the bundled image to the output
directory, byte for byte.

Built for the [Make the AI judge excited bounty](https://make.fun/bounty/ai-excited-01).
